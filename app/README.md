# تطبيق Cipheris - المراسلة اللامركزية والأمن السيبراني 🛡️💬

تطبيق أندرويد متكامل يعمل كعقدة مراسلة مشفرة ومستقلة تماماً، يهدف إلى توفير وسيلة تواصل غاية في الأمان والخصوصية باستخدام تكنولوجيا الأطراف (Peer-to-Peer) دون الحاجة لخوادم وسيطة تسجل بياناتك.

---

## ✨ أبرز الميزات المضافة حديثاً

1. **الروابط العميقة والتشغيل الفوري (`cipheris://`):**
   - يدعم التطبيق التسجيل الكامل لمخطط الروابط `cipheris://` على مستوى نظام أندرويد.
   - عند الضغط على أي رابط دعوة لقناة، مجموعة، أو تواصل مباشر مع عقدة، ينطلق التطبيق تلقائياً ويقوم بالتحليل الفوري للمعرفات.
   
2. **نافذة تأكيد الانضمام الآمن (Join Invitation Dialog):**
   - واجهة منبثقة تفاعلية ذكية تظهر فور التشغيل عبر الروابط العميقة.
   - تسأل المستخدم تأكيد الانضمام: *"هل تود الانضمام إلى [القناة/المجموعة/المستخدم]؟"* مع عرض الرمز التعريفي المشفر وخيار المزامنة أو الإلغاء وتفادي المراسلات العشوائية.

3. **توصيل وتزامن العقد اللامركزية (Decentralized Node Sync):**
   - يدعم التطبيق التواصل المباشر ومزامنة الرسائل والبيانات عبر شبكة من العقد المختلفة (مثل العقدة 3 والشبكات الداخلية) لضمان عدم وجود نقطة فشل واحدة واستمرار الاتصال محلياً وعبر الإنترنت.

4. **مشاركة كافة أنواع وتنسيقات الملفات (Telegram-like File Sharing):**
   - لم يعد إرسال المستندات مقتصرًا على ملفات الأوفيس والصور؛ حيث يتيح التطبيق الآن مشاركة جميع أنواع الملفات بشتى التنسيقات والامتدادات (بما فيها حزم التطبيقات **APK**).
   - يتم احتساب الحجم بدقة وعرض بصمة التشفير الرقمية SHA-256 للملف لضمان النزاهة والأمان المطلق.

5. **التحميل للجهاز وتثبيت ملفات الـ APK:**
   - زر مدمج بنقرة واحدة لتحميل وحفظ أي ملف يتم استقباله وتخزينه بأمان مفكك التشفير في المجلد العام المخصص `Downloads/Cipheris` على جهازك الفعلي.
   - إمكانية تثبيت تطبيقات الـ APK المحملة مباشرة عبر نافذة التثبيت التلقائية بنظام أندرويد من خلال تفعيل `FileProvider` التلقائي والآمن.
   - دعم التوجيه التلقائي للملفات المفتوحة لتعمل على البرامج الخارجية المناسبة المثبتة في الهاتف.

---

## 🔒 معمارية الحماية وسير العمل

* **التشفير الفوري على العقد (Local Encryption):** يتم تمرير كافة الملفات المحددة عبر خوارزمية AES-256 للتشفير المباشر وتوليد مفاتيح عشوائية فريدة قبل إتاحة مشاركتها.
* **فك التشفير المعزول (Zero-Knowledge View):** لا يتم كشف محتويات المستندات أو الوسائط إلا وقت العرض المباشر داخل مشغلات الوسائط وعارض المستندات المدمج بالتطبيق، وتُحذف كافة الملفات المؤقتة فور إغلاق واجهة العرض.
* **دعم اللغات الكامل:** التطبيق مهيأ بالكامل للغتين العربية والإنجليزية لتقديم أفضل تجربة مستخدم ممكنة ومبسطة للجميع.
